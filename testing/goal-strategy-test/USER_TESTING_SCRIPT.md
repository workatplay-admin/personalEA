# User Testing Script - Goal & Strategy Service

## Introduction for Test Facilitator

Thank you for helping us test the Goal & Strategy Service! This script will guide you through conducting user testing sessions. Please follow the script closely while allowing users to express their natural reactions.

## Pre-Test Setup

### For the Facilitator:
1. Ensure test environment is ready:
   - Application URL: http://localhost:3001
   - Test OpenAI API key available
   - Screen recording software ready
   - Note-taking materials prepared

2. Prepare test area:
   - Quiet environment
   - Stable internet connection
   - Modern web browser (Chrome preferred)
   - Mobile device if testing mobile experience

### Test Materials Needed:
- This script
- Consent form for recording
- Post-test questionnaire
- Note-taking template
- Timer/stopwatch

## Session Script

### 1. Welcome and Introduction (3 minutes)

**Say to participant:**

"Hi [Name], thank you for participating in our user testing session today. I'm [Your name], and I'll be guiding you through this session.

We're testing a new Goal & Strategy Service that helps people transform their goals into actionable plans using AI. We're interested in learning how easy or difficult it is to use, not testing your abilities.

Please remember:
- There are no wrong answers
- We want your honest feedback
- Please think out loud as you work
- Ask questions if you're confused
- This will take about 30-45 minutes

Do you have any questions before we begin?"

### 2. Consent and Recording (2 minutes)

**Say:**

"We'd like to record this session to help us review and improve the application. The recording will only be used internally for development purposes. 

Are you comfortable with us recording this session? [Get verbal consent]

Great! Let's begin. I'll start the recording now."

[Start screen recording]

### 3. Background Questions (3 minutes)

**Ask:**

1. "Can you tell me a bit about yourself and what you do?"
2. "Have you used any goal-setting or project planning apps before?"
3. "How comfortable are you with technology on a scale of 1-10?"
4. "What's a goal you're currently working on or thinking about?"

### 4. First Impressions (2 minutes)

**Say:**

"I'm going to show you the application now. Please take a moment to look at it without clicking anything, and tell me your first impressions."

[Navigate to application]

**Ask:**
- "What do you think this application does?"
- "What catches your attention first?"
- "Does anything confuse you?"

### 5. Task 1: Initial Setup (5 minutes)

**Say:**

"Now I'd like you to set up the application. Imagine you just found this tool and want to try it out."

**Observe and note:**
- Do they understand they need an API key?
- Can they find the configuration instructions?
- Any confusion about the setup process?

**If they struggle with API key:**
"For this test, I'll provide you with a test API key: [provide key]"

### 6. Task 2: Enter Your First Goal (5 minutes)

**Say:**

"Great! Now I'd like you to enter a goal. This can be the real goal you mentioned earlier, or any goal you're comfortable sharing."

**Observe and note:**
- Do they understand what kind of goal to enter?
- Do they notice the example goals?
- How long do they spend thinking?
- Do they use the examples or write their own?

**Prompting questions if needed:**
- "What are you thinking about?"
- "Is anything unclear?"
- "What would help you here?"

### 7. Task 3: Transform to SMART Goal (5 minutes)

**Say:**

"Now please transform your goal into a SMART goal using the application."

**Observe and note:**
- Do they find the transform button easily?
- Do they understand the loading state?
- Initial reaction to the SMART goal?
- Do they understand each component?

**Ask after transformation:**
- "How well does this match what you expected?"
- "Is anything confusing about the result?"
- "Do the suggestions make sense for your goal?"

### 8. Task 4: Interactive Refinement (8 minutes)

**Say:**

"I notice there's an option to refine your goal with AI chat. Could you try that feature?"

**Observe and note:**
- Do they find the chat interface?
- Are they comfortable interacting with it?
- Do they understand how to ask questions?
- Are the AI responses helpful?
- Do they notice the real-time updates?

**If they're stuck, suggest:**
"Try asking the AI about [specific aspect of their goal]"

### 9. Task 5: Complete Workflow (10 minutes)

**Say:**

"Now let's continue through the rest of the process. Please work through generating milestones, tasks, and time estimates."

**Observe and note:**
- Natural flow between steps?
- Any confusion points?
- Do the generated items make sense?
- Overall time to complete?

**Ask at each major step:**
- "Does this seem helpful?"
- "Anything surprising here?"
- "Would you change anything?"

### 10. Task 6: Specific Scenarios (5 minutes)

Choose 1-2 based on time:

**A. Mobile Experience** (if applicable)
"Could you try using this on your phone?"

**B. Error Recovery**
"What would you do if you got an error here?"

**C. Using Examples**
"Could you try starting over with one of the example goals?"

### 11. Wrap-up Questions (5 minutes)

**Ask:**

1. "Overall, how was your experience using this application?"
2. "What was the most valuable part for you?"
3. "What was the most frustrating or confusing?"
4. "Would you use this for your real goals? Why/why not?"
5. "What's missing that would make this more useful?"
6. "Would you recommend this to a friend?"
7. "Any other feedback or suggestions?"

### 12. Post-Test Questionnaire (3 minutes)

**Say:**

"Thank you so much! I have a quick questionnaire for you to fill out with some ratings."

[Provide questionnaire]

### 13. Closing (2 minutes)

**Say:**

"That completes our testing session. Your feedback has been incredibly valuable and will help us improve the application. 

Do you have any final questions for me?

Thank you again for your time!"

[Stop recording]

## Tips for Facilitators

### Do:
- Remain neutral - don't lead the participant
- Ask "What are you thinking?" often
- Let them struggle a bit before helping
- Take detailed notes on behavior
- Note emotional reactions
- Time each task

### Don't:
- Explain how features work unless asked
- Defend design decisions
- Rush the participant
- Skip sections even if running long
- Forget to record

### When Participants Get Stuck:
1. First: "What are you trying to do?"
2. Then: "What would you expect to happen?"
3. Finally: "Where would you look for that?"
4. Only give hints as last resort

### Recording Emotions:
- 😊 Delighted
- 🙂 Satisfied  
- 😐 Neutral
- 🤔 Confused
- 😟 Frustrated
- 😠 Angry

Note these alongside observations for emotional journey mapping.
